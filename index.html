About Me

Python developer by passion. Django engineer by profession. Building scalable web applications that solve real-world problems.

I'm a Python Full-Stack Developer specializing in the Django ecosystem. I build robust, scalable, and maintainable web applications—from backend architecture and RESTful APIs to database design and responsive frontend experiences.

My core expertise includes Python, Django, Django REST Framework, PostgreSQL, JavaScript, HTML, CSS, and Docker. I enjoy turning complex business requirements into clean backend systems, efficient APIs, and intuitive user experiences.

I've worked on everything from e-commerce and food delivery platforms to API-driven applications and real-time systems. I'm particularly interested in performance optimization, database architecture, API design, background processing with Celery, caching, and building applications that are ready to scale.

Beyond traditional web development, I'm exploring how AI and automation can be integrated into modern applications—using LLMs, intelligent workflows, and automation to build smarter products.
