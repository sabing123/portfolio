About Me

Engineer by trade. Builder by heart. A little too curious about how things work.

I'm a full-stack software engineer with deep roots in the Python and Django ecosystems. Over the years I've architected scalable web applications, designed RESTful APIs, and built data pipelines that quietly handle millions of requests — the kind of systems you can set and forget.

Lately I've been obsessed with AI agent architectures — teaching systems to think in steps with LangGraph, coordinating multi-agent workflows, and bringing LLMs into production without the fluff or the hype.

When I'm not shipping code, you'll find me tuning database queries, experimenting with the latest in generative AI, or losing track of time on a side project that starts small and never quite stays that way.
